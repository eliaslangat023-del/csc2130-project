## Project Description

The Student Records Management System (SRMS) is a web-based project designed to demonstrate how student information and academic records can be organized and presented through a website.

The project provides pages for student registration, student searches, viewing sample academic records, and contacting the system administrator.

## Technologies Used

- HTML5 – Website structure and content
- CSS3 – Styling, layout and responsive design
- Git and GitHub – Version control and project hosting

## Main Features

- Student registration form with input validation
- Student search form
- Student academic records displayed in a table
- Contact form
- Educational images and embedded video
- Consistent navigation across website pages
- Responsive layout for different screen sizes

## Project Limitations

This project currently demonstrates front-end web development using HTML5 and CSS3. The forms are not connected to a backend database, so student information is not permanently stored or retrieved.
