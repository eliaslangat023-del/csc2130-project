About the Project

The Student Records Management System (SRMS) is a web-based project designed to simplify the organization and management of student information and academic records.

Our Mission

Our mission is to make student information management simple, accurate and efficient through a digital platform.

Our Vision

Our vision is to provide a reliable and accessible system for managing academic records while reducing unnecessary paperwork.

This project uses semantic HTML, structured content, and future database integration.

How Users Use the Application

  1. Open the application.
  2. Register a new student.
  3. View available student records.
  4. Search for student information.
  5. Review academic records.

Technologies Used

HTML5
Used to structure the web pages and their content.
CSS3
Used to style the pages and create a consistent layout.
JavaScript
Planned for adding interactive functionality.
PHP
A server-side language planned for application logic.
MySQL
A database system planned for storing student records.

Project Note

The current application demonstrates the front-end structure and forms. PHP and MySQL integration will make it possible to store and retrieve student records dynamically.
